# OOP Shape Calculator & Visualizer

## Overview
This project is a Java-based application that calculates and visualizes different 2D and 3D geometric shapes using Object-Oriented Programming (OOP) concepts.

## Technologies Used
- Java
- Java Swing
- Java AWT

## OOP Concepts Applied
- **Inheritance:** Reusing properties and methods through parent and child classes.
- **Abstraction:** Defining common behavior for different shapes.
- **Interfaces:** Defining shared functionality.
- **Polymorphism:** Implementing different behaviors for different shape types.

## Key Features
- Calculates properties of 2D and 3D geometric shapes.
- Visualizes shapes using Java Swing and AWT.
- Uses inheritance, abstraction, interfaces, and polymorphism.
- Supports file handling.

## Project Goals
- Apply Object-Oriented Programming concepts in a practical application.
- Organize code using reusable and maintainable classes.
- Combine geometric calculations with graphical visualization.

## How to Run
1. Clone or download this repository.
2. Make sure Java JDK is installed.
3. Open the project in an IDE such as IntelliJ IDEA, Eclipse, or NetBeans.
4. Run the main Java class.
